# 🏡 Real-Time Mortgage Calculator

A clean, modern, and fully responsive mortgage payment calculator built using pure HTML, CSS, and JavaScript. It calculates monthly payment amounts dynamically as users enter loan details without requiring page refreshes or showing intrusive popups.

## ✨ Key Features
* **Live Calculations:** Instantly updates monthly payments on every keystroke using JavaScript `input` event listeners.
* **Responsive UI:** Modern, centered card design built with CSS Flexbox that scales seamlessly across mobile, tablet, and desktop screens.
* **Silent Error Handling:** Automatically handles empty or invalid numeric inputs with silent fallback values (`$0.00`) for a smooth user experience.

## 🛠️ Tech Stack
* **HTML5:** Form markup and structure
* **CSS3:** Flexbox layout, modern dark background gradients, and focus states
* **JavaScript (ES6+):** Dynamic DOM manipulation, mathematical formulas, and event handling
